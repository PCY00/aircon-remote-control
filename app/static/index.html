    ESP32-H2 Zigbee IR 연결

    이미 Zigbee2MQTT에 가입된 H2를 이 에어컨에 연결합니다. 등록 버튼은 필요하지 않아요. 새 보드는 ‘새 Zigbee 기기 추가’로 가입을 허용한 뒤 USB 전원을 연결하세요. 이미 가입된 보드는 아래 목록에서 바로 선택하면 됩니다. 실제 에어컨 상태는 읽을 수 없어요.

    새 모델 분석 요청

    제품 사진은 필수예요. 리모컨 사진과 PDF 매뉴얼이 있으면 분석 속도와 정확도가 좋아져요.

    센서 화면 자동 갱신

    센서를 깨우는 설정이 아니라, 이 화면이 서버의 최신 저장값을 다시 읽는 주기를 정합니다.

    Zigbee2MQTT

    센서 추가·관리

    연결 시간을 선택해 Zigbee 가입을 연 다음 센서의 리셋 버튼을 약 5초 누르세요. 창을 닫거나 시간이 끝나면 새 기기 연결도 자동으로 차단됩니다.

    새 센서 연결상태 확인 중
    1. 연결 시작을 누릅니다.
    2. 센서 리셋 버튼을 약 5초 눌러 LED가 깜빡이게 합니다.
    3. 아래 목록에 연결됨이 표시될 때까지 기다립니다.
    Zigbee2MQTT 기기Coordinator 제외

      연결된 Zigbee 기기를 불러오는 중이에요.

      아직 보고한 센서가 없어요. 페어링 후 센서를 한 번 작동시켜 주세요.
