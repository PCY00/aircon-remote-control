# 공기계 A50으로 가족 스마트홈을 만들어봤다

　라즈베리파이에서 읽는 집 소식을 휴대폰 알림으로 받고 싶었다. 노트북 대신 남는 Galaxy A50을 서버로 써보기로 하고, PC 접속부터 가족 앱과 알림까지 차례대로 만들었다.

　처음부터 한 번에 된 것은 아니었다. 재부팅 뒤 허용창에서 막혔고, 필요 없는 앱을 정리했는데 여유 메모리가 늘지 않기도 했다. 이런 과정과 실제로 확인한 범위를 함께 적었다.

　작성 기준은 2026년 10월 4일이고 서버와 앱 소스는 0.4.0이다. 최신 소스를 한 번 준비하면 된다. 예전 실행 결과는 당시 직접 해본 기록이며, 옛 APK를 차례대로 설치할 필요는 없다.

## 준비부터 화면 개선까지

---

| 글 | 여기서 하는 일 | 끝났을 때 확인할 것 |
| --- | --- | --- |
| 남는 Galaxy A50을 서버로 써봤다 | Wi-Fi, SSH와 부팅 후 접속을 준비했다. | 화면 꺼짐과 재부팅 뒤 자신의 A50에 접속한다. |
| A50에서 작은 서버를 돌려봤다 | 선택적으로 앱을 정리하고 서버를 설치했다. | 서버가 ready, 기록 파일이 ok로 응답한다. |
| 같은 앱을 써도 자기 집만 보게 만들었다 | Google 로그인과 가족 권한을 준비했다. | 서버에도 같은 Firebase 프로젝트가 저장된다. |
| Google 로그인하는 Android 앱을 만들었다 | 본인 설정과 서명으로 APK를 만들었다. | 휴대폰에서 Google 로그인이 된다. |
| 다른 휴대폰에서 A50 서버에 연결해봤다 | 시험용 HTTPS 주소와 첫 집을 만들었다. | 앱에서 집 목록과 집 화면을 읽는다. |
| 화면을 꺼둔 A50에 시험 알림을 보내봤다 | 서버 전송 키와 휴대폰 알림 받기를 준비했다. | 실제 시험 알림이 도착한다. |
| 라즈베리파이의 기록을 A50에 보내봤다 | 기존 Pi 기록을 읽어 보내게 했다. | 연결 알림과 새 센서 기록을 읽는다. |
| 받고 싶은 알림만 고르고 가족을 관리하게 했다 | 알림 선택과 집·가족 관리를 넣었다. | 선택이 저장되고 관리 화면을 사용할 수 있다. |
| 버튼을 누르면 맨 위로 올라가던 화면을 고쳤다 | 홈·기록·설정을 나누고 읽던 위치를 기억했다. | 저장하고 돌아와도 읽던 위치가 유지된다. |

　PC 준비 과정은 A50 접속 준비 글 안에 넣었다. 필요한 코드와 글, 사진은 [GitHub의 서버 코드](https://github.com/PCY00/aircon-remote-control/tree/main/server)에서 받는다. 링크를 열고 Code → Download ZIP으로 `main`의 현재 코드를 받은 뒤, 압축을 푼 저장소의 `server` 폴더를 사용한다. 개인 키와 실제 접속 설정, APK는 포함하지 않았다. 따라 만드는 사람은 본인 Firebase와 서명으로 APK를 만든다.

　Pi 기록 연결은 기존 센서 프로그램이 있는 경우에 진행한다. 그 프로그램이 아직 없으면 필요한 센서 기록부터 준비한다. 센서 없이도 서버와 앱 로그인, 시험 알림과 화면 설정은 진행할 수 있다.

## 게시할 때 사용하는 파일

---

　티스토리용 묶음에는 글마다 제목과 본문 HTML을 따로 넣는다. 본문은 HTML 모드에 붙여 넣고, 제목은 제목 칸에 넣는다. 사진은 티스토리에 직접 올린다. 코드는 첫 글에 넣은 공개 GitHub 링크로 받으므로 코드 ZIP을 따로 첨부할 필요가 없다. 본문 HTML에는 로컬 문서 링크나 보이지 않는 로컬 사진 주소를 넣지 않는다.

　실제 실행 결과 중 판단에 필요한 줄은 본문에 넣었다. 그림이 없는 상태에서도 명령어와 결과, 오류를 해결한 과정을 읽을 수 있게 했다. 사진 파일은 위치정보를 없앤 공개용 자료이며, 앱 화면의 이메일과 장비 주소를 가렸다.

　문을 직접 열고 닫아서 오는 알림, 실제 온습도 알림, 서로 다른 가족 계정의 실제 수신과 장시간 운영은 별도로 확인할 일이 남아 있다. 새 PC와 새 휴대폰으로 모든 과정을 다시 끝냈다고 쓰지는 않았다.
