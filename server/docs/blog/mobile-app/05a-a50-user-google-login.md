# A50에도 가족 앱으로 Google 로그인하기

4편에서 가족 앱을 설치하고 5편에서 서버 주소를 준비한다. 7편의 PC 연결 도구를 사용하려면 서버용 A50에도 가족 앱이 있어야 하고, 연결할 집의 소유자로 로그인돼 있어야 한다.

A50 설정에서 Google 계정을 추가한 뒤 가족 앱의 ‘Google로 계속하기’를 누른다. 계정 선택과 비밀번호는 본인이 직접 입력한다. 비밀번호를 명령어에 넣거나 다른 사람에게 보내지 않는다.

5편에서 만든 본인 HTTPS 주소를 연결 설정에 넣는다. 다른 휴대폰에서 이미 만든 집이 있다면 **같은 Google 계정**으로 로그인했을 때 그 집이 보인다. 새 집을 중복으로 만들 필요가 없다. 6편에서 ‘이 휴대폰에서 받기’도 켜고 시험 알림을 받는다.

작성자는 멀리 떨어진 A50 화면을 보며 본인이 직접 로그인한 뒤 결과를 확인했다. 독자에게 특정 원격 화면 도구나 작성자의 계정이 필수인 것은 아니다. 화면을 공개할 때는 계정 이메일과 서버 주소를 가린다.
