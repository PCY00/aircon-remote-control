# iPhone 크기의 웹앱 화면 자료

2026-10-16 중앙 서버 0.8.0의 웹앱을 PC 브라우저에서 390×844 크기로 열어 찍었다. 가상 계정·가상 기기·개발용 토큰을 쓴 화면이고 `개발 모드`가 표시된다. 실제 iPhone에서 촬영한 사진이나 실제 로그인·푸시 수신 결과는 아니다.

- `01`: 홈의 지금 확인할 것·공간별 기기 타일.
- `02`: 에어컨 냉방 설정을 25도로 바꾸어 전송한 가상 결과.
- `03`: 같은 문 기록 묶기와 끔으로 둔 정기 보고 숨기기.
- `04`: 홈 화면 추가 안내와 일곱 알림 종류의 중요도.

[iPhone 사용 안내](../../../ios-web-app.md)에 네 사진을 배치했다. 실제 iPhone 계정 로그인·홈 화면 추가·알림 허용·푸시 수신 확인은 남아 있다. 공개 사진에는 계정과 접속 정보가 없고 위치·촬영 정보도 제거했다.
