# Android 가족 앱 화면 자료

현재 앱은 0.6.2·빌드 번호 12다. `45`~`53`번은 A50을 세운 상태에서 가상 계정·가상 기기로 확인한 세로 화면이며, `36`~`44`번은 앞서 찍은 가로 화면이다. 실제 가족의 이름·계정·집 상태나 실제 푸시 수신의 증거로 사용하지 않는다.

- `45`·`46`: 지금 확인할 것과 공간별 기기 타일.
- `47`·`48`: 냉방·자동 운전. 부가 기능 다섯 개와 전송 버튼이 세로 한 화면에 보인다.
- `49`·`50`: 환경 종류와 문 센서 상세.
- `51`·`52`·`53`: 알림 묶기·종류별 중요도·집 바꾸기.

[앱 설명과 화면 표](../../../../android/family-app/README.md)에서 사진을 직접 본다. 0.4.0 이전 실계정 시험 사진은 저장소 루트의 `docs/assets/hardware/family-app/`에 당시 설명과 함께 보관했다. 공개 사진의 위치·촬영 정보는 제거했다.
