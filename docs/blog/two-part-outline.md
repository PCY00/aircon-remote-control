# 이전 블로그 2편 구성 초안

> 이 문서는 초기 계획을 보존하기 위한 기록이다. 실제 게시 구성은
> [4편 블로그 구성](README.md)으로 변경했다.

## 1편 — 오래된 에어컨 리모컨을 해부하고 신호를 복제하기까지

- 프로젝트를 시작한 이유와 목표
- 기존 리모컨 PCB 분해·식별
- IR 방식임을 확인한 근거
- 수신·송신 모듈 선택과 GPIO 안전
- 반송파 및 원시 신호 캡처
- 에어컨 리모컨이 전체 상태를 전송한다는 점
- 실패한 캡처와 타이밍 문제
- OFF 및 냉방 프리셋 재생 성공

## 2편 — Raspberry Pi와 Tailscale로 외부 제어 시스템 만들기

- Raspberry Pi OS Lite 초기 설정
- 로컬 기준본과 승인 기반 배포 구조
- FastAPI와 포트 8001
- systemd 자동 시작과 로그 관리
- Tailscale 사설망 접속
- 모바일 UI 설계와 실제 제어
- 상태 불일치·명령 누락 대응
- 운영 중 발생한 장애와 개선점

실제 측정값과 화면은 진행 과정에서 추가하며, 아직 수행하지 않은 결과를 미리 작성하지 않는다.
