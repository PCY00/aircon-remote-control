# 원인
ProtectSystem=strict 보안 격리 아래에서 /run/user/1000이 쓰기 예외가 아니었다.
Cage가 XDG_RUNTIME_DIR에 Wayland 소켓을 만들지 못해 Chromium이 시작되지 않았다.

# 로컬 수정안
ReadWritePaths=/run/user/1000
XDG_RUNTIME_DIR=/run/user/1000
XDG_CACHE_HOME=/home/air/aircon-controller/runtime/kiosk/cache
전체 홈과 시스템 경로의 읽기 전용 보호는 유지
