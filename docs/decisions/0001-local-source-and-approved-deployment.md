# ADR-0001: 로컬 기준본과 승인 기반 단방향 배포

- 상태: 채택
- 날짜: 2026-08-29

## 배경

개발은 Windows 로컬 폴더에서 진행하고 실제 GPIO와 IR 장비 검증은 Raspberry Pi에서 수행한다. 두 위치에서 동시에 코드를 수정하면 버전 충돌과 원격 변경 손실 위험이 있다.

## 결정

- 로컬 작업공간을 유일한 기준본으로 사용한다.
- Raspberry Pi는 실행·하드웨어 검증용 배포 대상으로 사용한다.
- 배포는 로컬에서 Raspberry Pi로만 수행한다.
- 실제 원격 변경 전마다 변경 파일, 대상 경로와 주요 명령을 제시하고 승인을 받는다.

## 결과

- 양방향 자동 동기화는 사용하지 않는다.
- Raspberry Pi에서 발견된 예상 밖 변경은 자동으로 덮어쓰지 않는다.
- 배포 도구는 dry-run과 변경 파일 확인을 지원해야 한다.
