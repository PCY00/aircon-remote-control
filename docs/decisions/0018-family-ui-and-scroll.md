# 가족 앱의 화면 구분과 스크롤 유지

2026년 10월 2일. 사용자는 버튼을 누를 때 맨 위로 이동하는 문제와 복잡한 화면을 지적했고 인터넷 참고를 요청했다.

홈과 기록과 설정을 같은 단계의 하단 목적지로 둔다. 홈에는 요약과 최대 세 개의 최근 기록만 둔다. 가족과 기기 관리, 연결 주소, 삭제는 설정으로 옮긴다. 집 상태는 인증된 실제 기록만 사용하며 값이 없거나 최근 기록에서 찾지 못하면 확인되지 않은 상태로 표시한다.

알림 상세의 저장과 연결 확인은 상태만 갱신한다. 설정 변경 리스너는 편집 중인 알림 선택을 다시 만들지 않는다. 앱의 `onResume()`에서 기존 화면을 집 목록으로 바꾸지 않는다. 화면과 집별 위치를 기억해 탭 이동, 뒤로 이동, 새로고침 때 복원한다.

전용 서명과 기존 계정 및 설치 설정을 유지한다. 서버 권한과 화면 세대 검사는 그대로 적용한다. 실제 사용자 집 삭제, 앱 데이터 초기화나 서버 및 터널 재시작으로 UI를 검증하지 않는다.

[인터넷 근거와 실제 검증](../blog/mobile-app/09-ui-redesign-and-scroll.md). 실제 native 검사는 알림 상세 315px과 홈 새로고침 200px 위치 유지, 앱 복귀의 미저장 선택 유지와 필터를 확인했다. 프로세스가 종료된 뒤 미저장 선택 복구는 검증 범위가 아니다.
