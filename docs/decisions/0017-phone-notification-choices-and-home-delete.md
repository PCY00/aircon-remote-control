# 휴대폰별 알림 선택과 집 삭제

2026-10-02. 사용자 승인 선택: 휴대폰별 종류, 온습도 1·5·15·60분 간격. 집 추가·삭제와 UI/UX 개선도 요청했다.

- 선택은 설치별이며 현재 사용자와 설치 증명으로만 갱신한다. 가족 권한은 별도로 매 요청 검사한다.
- 기본은 문·경고 켜짐, 온습도 꺼짐. 같은 계정의 다른 폰은 영향을 받지 않는다.
- 온습도 최신 행을 읽기 전용으로 관찰하며 기존 행은 첫 기준으로 건너뛴다. 새 보고의 유효 값만 중앙으로 보낸다. 원시 ID는 로컬 namespace를 포함한 SHA-256 참조로 바꾼다.
- 간격은 측정 주기나 정시 타이머가 아니라 휴대폰별 다음 전송 예약의 최소 간격이다. 여러 집·온습도 센서를 통틀어 해당 설치에 적용한다.
- 전송 대기열과 직전 권한 검사에 선택을 적용하고 단말도 다시 검사한다. 일반 종류·시험 알림은 기존 전달을 유지한다.
- 온습도는 NORMAL 우선순위·별도 조용한 채널, 문/경고는 기존 채널이다. 수치는 인증된 집 API에서 조회하고 FCM에는 싣지 않는다.
- 집 삭제는 소유자·이름 확인 후 목록/권한/허브/초대/대기 알림을 원자적으로 비활성화한다. 내부 감사 기록은 보존한다. 이미 수락된 FCM 메시지는 회수하지 못한다.
- 스키마 4 추가 변경은 기존 계정·집·설치·키를 보존한다. 실제 사용자 집을 삭제해 기능을 시험하지 않는다.
