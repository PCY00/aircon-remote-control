# 0010 — Zigbee 장치는 제한 시간 동안 한 대씩 페어링한다

## 상태

채택 — 2026-09-06

## 배경

상용 Zigbee 센서 두 대의 외관 모델명은 확인했지만 실제 Zigbee 식별자와
Zigbee2MQTT 지원 여부는 인터뷰 전에는 알 수 없다. 장치 가입을 계속 허용하면 의도하지
않은 주변 장치가 같은 네트워크에 들어올 가능성이 있고 어떤 실험이 어떤 장치의 결과인지
구분하기 어려워진다.

## 결정

- 기본 `permit_join`은 꺼 둔다.
- 한 번에 장치 한 대만 전원을 넣거나 초기화한다.
- 가입은 Coordinator를 대상으로 기본 180초만 허용하며 최대 254초를 넘기지 않는다.
- 인터뷰 결과를 확인하면 남은 시간과 관계없이 즉시 가입을 닫는다.
- 온습도 센서를 먼저 연결하고 충분히 관찰한 다음 도어센서를 연결한다.
- 표시 이름은 실제 인터뷰가 성공한 뒤 정하며 장치 IEEE 주소와 분리한다.
- 공개 캡처에서는 IEEE 주소, PAN 정보와 네트워크 키를 제거한다.

## 결과

페어링 과정과 MQTT 메시지를 장치별로 명확히 추적할 수 있고 불필요하게 Zigbee
네트워크를 열린 상태로 두지 않는다. 대신 두 장치를 차례로 작업해야 하므로 페어링에
조금 더 시간이 걸린다.
