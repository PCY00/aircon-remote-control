# 결정 0006 — 지원 프로필과 런타임 업로드 분리

- 상태: 채택
- 날짜: 2026-08-30

## 결정

지원 모델 프로필과 패킷은 `device_profiles/`에서 소스 관리한다. 사용자가 제출하는
미지원 모델 사진과 매뉴얼은 `runtime/device_requests/`에 저장하고 코드 동기화 대상에서
제외한다. Markdown은 실행 입력으로 해석하지 않고 `commands.json`만 런타임 명령 데이터로
사용한다.

## 이유

- 모델별 검증 자료와 실행 데이터를 함께 리뷰할 수 있다.
- 코드 배포가 Pi에 업로드된 사용자 자료를 덮어쓰거나 삭제하지 않는다.
- 에어컨·TV·조명과 향후 Zigbee 노드를 같은 상위 카탈로그로 확장할 수 있다.
- 문서 표현을 고쳐도 송신 데이터가 뜻하지 않게 변하지 않는다.

## 결과

지원 프로필을 추가하려면 기기 종류·브랜드·모델 디렉터리와 JSON 명령 데이터를 함께
추가한다. 미지원 요청은 분석 완료 후 검증된 프로필로 수동 승격한다. 배포 스크립트는
앞으로도 `runtime/`을 동기화하거나 삭제하지 않는다.
