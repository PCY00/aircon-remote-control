# ADR-0002: FastAPI 웹/API와 포트 8001

- 상태: 채택
- 날짜: 2026-08-29

## 배경

스마트폰에서 에어컨 상태를 설정하고 명령을 보낼 UI가 필요하다. Raspberry Pi OS Lite에서 GUI 없이 가볍게 운영하고, 이후 IR 제어 및 Tailscale 접근을 같은 서비스에 통합해야 한다.

## 결정

- Python FastAPI와 Uvicorn을 사용한다.
- 웹/API 서비스 포트는 `8001`로 고정한다.
- UI 구현 전에는 상태 확인 엔드포인트만 운영한다.
- 부팅 자동 실행과 장애 복구는 Raspberry Pi에서 systemd로 관리할 예정이다.

## 결과

- API와 UI를 같은 포트에서 제공할 수 있다.
- 개발 서버의 자동 재시작 옵션은 로컬에서만 사용한다.
- 외부 접근은 Tailscale 사설망으로 제한하고 공용 포트포워딩은 사용하지 않는다.
