# 2026-08-30 로컬 아이콘 시스템과 사용자 선택기

## 목표

임시 문자로 표시되던 스마트홈 아이콘을 일관된 SVG 아이콘으로 교체하고, 사용자가 빠른
장면·공간·기기를 추가하거나 설정할 때 원하는 아이콘을 직접 고를 수 있게 한다.

## 문제 확인

- HTML 요소에는 `sofa`, `door-open`, `lamp-floor`, `tv` 같은 Lucide 이름이 이미 있었다.
- 실제 Lucide 스크립트는 로드하지 않았고 CSS `::before`의 유니코드 문자가 표시됐다.
- 문자 글꼴과 운영체제에 따라 모양이 달라 스마트홈 기기 아이콘으로 보이지 않았다.
- `Mock IR 연결 · 실제 송신 없음`은 완료 상태용 녹색을 어두운 요약 패널에서도 사용해
  대비가 낮았다.

## 구현

- Lucide `1.37.0`의 UMD 브라우저 번들과 ISC 라이선스를 `app/static/vendor/`에 보존
- FastAPI가 `/static` 경로에서 로컬 정적 파일을 제공하도록 구성
- 임시 문자 아이콘 CSS 제거 후 실제 SVG 렌더링 적용
- 자주 쓰는 25개 아이콘을 한글 이름과 묶은 공용 선택기 구현
- 빠른 장면 추가 폼과 기존 장면 설정에 아이콘 선택기 연결
- 공간 추가 폼과 기존 공간 설정에 아이콘 선택기 연결
- 기기 추가 3단계에 아이콘 선택기 연결
- 등록 기기의 `icon` 값을 API 요청과 런타임 JSON에 저장
- 하단 메뉴는 `house`, `layout-grid`, `workflow`, `ellipsis`로 통일
- `집에서` 기본 아이콘은 의미가 더 직접적인 `house`로 변경
- 상단 연결 상태는 별도 배지 없이 어두운 요약 패널 위의 흰색 텍스트로 단순화
- 빠른 장면 카드의 위쪽 패딩을 늘려 아이콘과 카드 상단 사이의 여백을 확보
- 누락됐던 `sr-only` 스타일을 추가해 접근성 알림의 화면 노출 방지

## 검증

자동 검사:

- Python 테스트: 24개 통과
- Ruff (`app`, `tests`): 통과
- 인라인 JavaScript 문법 검사: 통과

인앱 브라우저 `http://127.0.0.1:8001/` 검증:

1. 임시 `i[data-lucide]` 0개, 실제 `svg[data-lucide]` 52개 확인
2. 장면 아이콘 설정에서 `집에서`의 선택값과 카드 SVG 변경 확인
3. 공간 설정에서 `거실 → 주방 → 거실` 선택 상태와 최종 SVG 확인
4. 기기 추가에서 기본 `에어컨` 아이콘을 `TV`로 선택할 수 있음을 확인
5. 장면: `house`, `door-open`, `moon-star`
6. 기기: `snowflake`, `lamp-floor`, `tv`, `wind`
7. 하단 메뉴: `house`, `layout-grid`, `workflow`, `ellipsis`
8. 상단 Mock IR 상태: 투명 배경, 모서리 반경 0px, 흰색 `rgb(255, 255, 255)`
9. 빠른 장면 카드: 실제 높이 105px, 첫 아이콘 위쪽 여백 18px
10. 브라우저 warning/error 0건

## 범위와 후속 작업

- 아이콘 선택값은 등록 기기의 경우 서버 런타임 데이터에 저장된다.
- 장면과 공간 자체의 서버 영구 저장은 아직 후속 범위이므로, 현재 아이콘도 해당 UI
  객체의 수명과 동일하게 브라우저 세션에서 유지된다.
- 이번 변경은 로컬 기준본과 로컬 8001 서버에만 반영했고 Raspberry Pi에는 배포하지 않았다.
