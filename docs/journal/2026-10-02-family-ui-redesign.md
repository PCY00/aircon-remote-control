# 가족 앱 UI 개편 기록

2026년 10월 2일. 요청은 버튼의 맨 위 이동 문제 수정과 인터넷 참고를 통한 전체 UI 개선이다. Google Home 공식 개편 소개와 Android의 탐색 및 접근성 문서를 확인했다.

확인한 원인은 알림 버튼의 화면 전체 재생성과 앱 복귀 시 `onResume()`의 무조건적인 집 목록 이동이다. 홈과 기록과 설정을 나누고, 알림 상태를 현재 화면에서 갱신하며 집과 화면별 위치를 복원하도록 수정했다. 중앙 서버와 Pi 코드, 런타임 데이터를 배포하거나 삭제하지 않았다.

초기 A50 검사 330은 315px 위치와 미저장 선택 복귀를 통과했다. 실제 캡처에서 보인 native 버튼의 기본 그림자를 없애고 시스템 탐색 버튼의 밝은 배경 대비를 설정했다. 기록 화면 새로고침은 기록 화면을 유지하고 알림 상세에서 하단 설정을 누르면 설정 첫 화면으로 돌아가게 다듬었다.

최종 배포 APK 빌드 331, 구성과 서명 검사 333, 업데이트 설치 335를 완료했다. native 검사 336은 17.549초 통과했다. 저장 및 연결 확인 및 복귀 및 뒤로 이동에서 알림 상세 315px, 홈 새로고침과 탭 복귀 200px을 유지했다. 미저장 선택은 저장된 값을 바꾸지 않았다. 앱 재실행에서도 실제 로그인과 집을 유지했다.

읽기 전용 점검 332 당시 계정 1개, 집 2개, 허브 1개, 설치 2개, 이벤트 3개였다. 연결 시험 한 개와 온습도 보고 두 개가 있었으며 최신 보고는 26.21°C 및 26.99%였다. 알림 선택은 두 설치가 각각 문 1 온습도 0 경고 1 간격 5분, 문 1 온습도 1 경고 1 간격 15분이었다. 다른 휴대폰 설정을 수정하지 않았다. DB 무결성과 중앙 readiness는 정상이다.

알림 안내 검사 338은 아래에 있는 시험 버튼에서 위의 선택 버튼으로 이동할 때 검사 도구의 단방향 스크롤 때문에 실패했다. 실패 원문과 직전 실제 안내 화면을 보존했다. 접근성 노드의 위치와 스크롤 영역을 비교해 위로도 탐색하도록 도구를 수정했고 같은 운영 APK에서 검사 341이 9.407초 통과했다. 소유자 가족 화면과 틀린 이름 삭제 차단도 확인했다. 실제 집을 삭제하지 않았다. 화면 꺼짐 FCM 검사 342는 7.342초 통과했다. 새 콜백과 실제 알림 게시 때까지 비활성 화면을 확인했다. 최종 점검 343에서 로컬 및 바탕화면 및 설치 APK 해시가 일치했다. 최신 빌드 스테이징의 주요 소스와 리소스 및 버전 16개가 로컬과 같았다. 기존 집 2개 허브 1개 설치 2개와 두 휴대폰의 서로 다른 선택을 유지했고 중앙 서비스와 터널은 재시작하지 않았다. 마지막에는 홈 화면과 화면 꺼짐으로 복구했으며 SSH와 중앙 readiness 및 DB 무결성과 자동 무선 ADB 상태를 확인했다. [따라 하기와 화면](../blog/mobile-app/09-ui-redesign-and-scroll.md).

최종 자료 검사 344는 새 실제 TXT와 PNG 18쌍, 이미지 425개의 비공개 메타데이터 0개, 변경 텍스트 33개의 민감 값 검사와 문서 내부 연결 48개 및 단위 검사 4개와 diff 공백 검사를 통과했다. 감사 기록 자체의 새 PNG도 EXIF와 부가 정보를 비워 생성했다. 실패 자료도 함께 보존했다.
