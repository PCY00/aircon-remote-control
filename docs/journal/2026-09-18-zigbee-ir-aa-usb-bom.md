# 2026-09-18 — AA·USB-C ESP32-H2 IR 노드 BOM 초안

## 요청과 범위

사용자는 ESP32-H2-MINI-1-H4S 모듈, IR LED, MOSFET, USB-C와 AA 2개로
동작하는 신규 PCB의 BOM을 요청했다. PCB·배터리 후속 시리즈에 해당하며,
기존 Zigbee Step 4의 실기 검증 완료를 의미하지 않는다.

## 결정 및 미확정 사항

- LR6 알카라인 AA 2개 직렬, 충전 없음. USB 전원 우선 자동 선택안으로 작성했다.
- TPS2116 전원 선택 → TPS63802 승강압 → H2·IR 공통 3.3 V.
- TSAL6200 940 nm LED, AO3400A, 33 Ω을 최초 IR 시험 후보로 선정했다.
- 핵심 부품의 제조사 자료 및 JLC 등록을 확인했다. 인덕터는 LCSC 등록만 확인했다.
- Standard PCBA·X-ray 비용과 스루홀 조립 여부를 별도 검토하도록 표시했다.
- 저전압 차단 회로, 일부 수동소자·퓨즈·스위치의 정확한 MPN, 견적은 미확정이다.
- 이번 결과는 회로 설계용 후보 BOM이며 그대로 제조 주문하면 안 된다.
- 6~12개월 수명, IR 거리, 실제 전류, 새 PCB 동작은 측정하지 않았다.

## 파일 검증과 문제 기록

- 33개 품목 행, 기본 수량 합계 44개(AA 건전지 2개 포함, DNP 수량 0).
- 제작 대수 1대·5대에서 각 총수량 수식을 검증하고 최종 파일은 1대로 저장했다.
- BOM·구매 정보·설계 조건 3개 시트를 렌더링해 확인했다.
- 초회 미리보기에서 수량 라벨 잘림과 0805 패키지의 숫자 표시 문제를 발견했다.
  라벨을 줄이고 패키지에 단위를 붙여 수정 후 다시 렌더링했다.
- 생성 도구 호출은 종료 코드 1을 보고했으나, 파일 저장 완료 로그 및 Node 종료 이벤트
  코드 0이 함께 확인됐다. 이 불일치의 근본 원인은 이번 작업에서 확정하지 못했다.
- 별도 읽기 전용 검사에서 XLSX ZIP CRC, 3개 시트, 수식 33개, 기본 수량이 통과했다.
  저장된 오류 셀은 0개였다. 생성 도구 종료 코드 문제를 하드웨어 문제와 혼동하지 않는다.
- 검증 범위는 문서·파일·수량 계산이다. 실물 회로 검증은 별도다.
