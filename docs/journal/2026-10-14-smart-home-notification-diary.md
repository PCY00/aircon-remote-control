# 스마트홈 알림 — 2026-10-14

## SW 아키텍처를 컴포넌트 그림으로 새로 그렸다

　컴포넌트 형식으로 소프트웨어 아키텍처를 그려 달라고 했다. 기존 `docs/architecture/smart-home-components-a0.svg`는 10월 5일 구조라 가족 앱 원격 제어 경로가 빠져 있었다. 그래서 현재 로컬 코드를 기준으로 새 그림을 만들었다.

　먼저 실제 코드에서 클래스와 연결을 다시 읽었다. 확인한 범위는 Pi 앱의 서비스·저장소, Pi 연결 서비스의 `LocalController`·`ControlChannel`·`Sender`, A50 서버의 `Households`·`Controls`·`PushStore`·`FirebaseIdentity`다. 가족 앱의 화면·API·푸시 클래스, H2 펌웨어의 ZCL 클러스터·작업 큐·인코더·RMT도 확인했다. 실행 장치(휴대폰·A50·Pi·H2·하드웨어)를 큰 상자로, 프로세스와 서비스를 안쪽 상자로 나눴다. 흐름은 다섯 가지 색으로 구분했다: 집 안 제어, 가족 앱 원격 제어, 센서, 가족 알림, 로그인·인증.

　그림은 `scripts/render_sw_component_diagram.py`가 만든다. 컴포넌트마다 해당 코드 파일을 적어 두고, 파일이 없거나 글자가 상자를 넘으면 멈추게 했다. 처음 그린 그림에서는 외부 서비스 제목이 연결선과 겹쳤고, Pi 연결 서비스 상자의 마지막 줄이 잘렸다. 둘 다 고쳤다. USB 코디네이터가 Docker 상자 안에 들어가 있던 것도 하드웨어로 밖으로 뺐다. Google 공개 키 캐시는 코드를 다시 읽어 ‘max-age만큼 캐시, 만료 후 1시간 유예’로 바로잡았다.
