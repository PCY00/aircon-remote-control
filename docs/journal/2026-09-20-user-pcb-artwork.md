# 2026-09-20 — 사용자 원본 PCB 아트워크에서 다시 시작

## 작업 상태

**사용자 검토용 시제품 제조 패키지 완료. 실물 검증·주문 승인은 하지 않았다.** 배선, KiCad 검사, 제조 파일 생성 및 독립 Gerber/드릴 재읽기를 마쳤다. 사용자가 결과를 검토한 뒤 주문 여부를 결정한다. 이 기록은 PCB·배터리·제품화 후속 작업에 해당하며, 앞선 Zigbee/MQTT Step 1~4의 완료 여부와 구분한다.

사용자의 최신 지시에 따라 별도로 만든 `codex-revA`가 아니라, 사용자가 직접 작성한 `IR_ESP32H2.kicad_sch`와 `IR_ESP32H2.kicad_pcb`를 이번 작업의 입력 기준으로 삼았다. 사용자 배치 의도를 보존하면서 배선과 제조 검증을 완료하는 것이 목적이다.

## 보존과 작업본 분리

- 변경 전에 `user-design-20260920-022829` 스냅샷을 만들고 254개 파일을 검증했다.
- 이전 `codex-revA`는 활성 프로젝트에서 분리하여 같은 스냅샷의 `retired-codex-revA`에 복구 가능하게 보관했다. 새 작업의 회로·배치를 이전 Rev A로 덮어쓰지 않는다.
- 실제 수정은 `artwork-current` 작업본에서 진행한다. 원본 회로도·PCB 파일 해시는 변경되지 않았음을 확인했다.
- 현재 사용자 설계는 전기 부품 42개다. 잠긴 BT1, D1, J1, SW3, U2의 좌표·회전·면을 보존한다.
- BT1 배터리 홀더는 뒷면, 나머지 부품은 앞면이라는 사용자 지정을 유지한다. 외곽 크기는 기존 85 × 40mm를 유지한다.

## 초기 검사: ERC 0건으로 놓치는 문제

원본 회로도 ERC는 0건이었고 회로도와 PCB의 패드 네트 차이도 0건이었다. 그러나 초기 PCB DRC에는 121건의 위반과 68건의 미연결 항목이 있어, 이 상태를 제조 완료로 볼 수 없었다. 이 수치는 **수정 전 입력 상태**이며 최종 결과가 아니다.

특히 SW1 RESET, SW2 BOOT 버튼은 검사 통과 여부와 별개로 실제 부품 접점이 잘못 매핑되어 있었다.

| 항목 | 기존 설정 | 제조사 도면 확인 결과 |
| --- | --- | --- |
| 위쪽 두 단자 | 풋프린트 패드 1, 2 | A와 B는 누르지 않아도 내부 연결 |
| 아래쪽 두 단자 | 풋프린트 패드 3, 4 | C와 D는 누르지 않아도 내부 연결 |
| 누름 동작 | 일반 2핀 스위치 심볼로 표현 | 위쪽 접점 묶음과 아래쪽 접점 묶음을 연결 |

기존 심볼은 SW1.1=EN, SW1.2=GND 및 SW2.1=BOOT, SW2.2=GND였다. 따라서 실제 부품을 그대로 실장하면 EN과 BOOT가 각각 항상 GND에 연결된다. ERC는 풋프린트의 금속 접점 내부 구조까지 알지 못하므로 이 문제를 보고하지 않았다. 이는 실물 불량을 측정한 결과가 아니라, 제조사 접점 도면과 설계 연결을 대조하여 확인한 제작 전 오류다. [XKB TS-1187A 제조사 도면](https://datasheet.lcsc.com/datasheet/pdf/56c8799ae5193945a16a1ffbe378246a.pdf)

해결은 회로 의미나 버튼 형상을 바꾸는 것이 아니라, 풋프린트 위쪽 두 패드를 `1/1`, 아래쪽 두 패드를 `2/2`로 매핑하는 것이다. 임시 감사용으로 `TS-1187A-B-A-B_XKB_2Pin`을 만들었지만, 최종 프로젝트에서는 **프로젝트 내부 라이브러리의 `cypark:TS-1187A-B-A-B_XKB`에 수정된 매핑을 저장**했다. `_2Pin`은 최종 사용 라이브러리 이름이 아니다. 패드 위치·크기는 유지했으며, 최종 배선 후 네트 일치와 미연결 검사를 다시 통과했다.

## 작업본에 반영한 내용

1. SW1/SW2의 실제 접점에 맞게 패드 번호를 수정했다.
2. 하단 외곽선에서 중복된 5mm 선분을 제거했다. 전체 보드 외곽 크기는 바꾸지 않았다.
3. 잠기지 않은 부품을 기존 외곽 안으로 정리했다. 잠긴 5개 부품의 배치·회전은 유지했다.
4. 모듈 패드 안에 있던 비아 9개를 제거하고 패드 사이의 솔더마스크로 덮는 비아 4개로 대체했다. 이 4개 비아의 드릴 가장자리에서 패드까지 최소 간격은 약 0.22123mm다. 설계상 납 흡입 경로를 줄였지만 제조사가 텐팅을 실제 적용하는지는 주문 미리보기와 공정 조건에서 확인해야 한다.
5. 그 외 사용자 배선을 가능한 범위에서 유지하며 중요 전원·IR·USB 구간을 수동 배선했고, 로컬 `freerouter` 결과를 회수하여 보완했다. 최종 배선·비아 항목은 402개, 미연결은 0건이다. USB 짧은 배선과 연결 부하도 검토했으나 USB 규격 적합성 시험을 수행한 것은 아니다.
6. 최종 비아는 38개다. 드릴 0.3mm가 36개, 0.4mm가 2개이며 모두 텐팅으로 설정했다.
7. F1/F2/L1은 정확한 부품 자료와 패드를 대조한 뒤 아래와 같이 정리했다.

| 부품 | 최종 패드와 중심 간격 | 근거 |
| --- | --- | --- |
| F1 BNstar SMD1206-050C-16V | 1.25 × 2.00mm, 중심 ±1.40mm | 제조사 최대 몸체 폭 1.90mm에 여유를 둔 **설계상 조정**. 제조사 제공 권장 패드 도면이라고 표현하지 않는다. |
| F2 Yenji SMD1206P100TF | 1.00 × 1.90mm, 중심 ±1.50mm | 제조사 권장 land의 명목 치수 적용 |
| L1 Murata DFE201612E-R47M=P2 | 0.80 × 1.80mm, 중심 ±0.80mm | 제조사 권장 land 적용. 양면 중앙 코어 영역 동박 금지와 몸체 아래 비아 금지 영역 추가 |

퓨즈와 인덕터 판단 근거는 [BNstar 정확한 부품 자료](https://datasheet.lcsc.com/datasheet/pdf/9805b486ee62b848d009b5edc742c366.pdf), [Yenji 제조사 자료의 5쪽 패드 도면](https://file.elecfans.com/web2/M00/78/08/poYBAGNoe5eAXgHvAAWgpvrl3s4691.pdf), [Murata 권장 패드·주의사항](https://pim.murata.com/asset/pim4/inductor/J(E)TE243A-0006_PDF_INDUCTOR)을 확인했다. 자세한 수치와 해석 범위는 감사 자료 `passive-land-review.md`에 남겼다.

R16은 실제 풋프린트에 맞게 0805 표기로 수정했다. USB ESD 소자는 선택한 비-A형 부품과 데이터시트가 일치하도록 정리했다. 42개 부품의 제조사 번호와 해당하는 LCSC 코드 등 조달 필드를 프로젝트에 반영했다. 수동 납땜 부품은 PCBA 대상과 구분한다.

## 라이브러리 스냅샷 과정의 좌표 오류와 해결

프로젝트 내부 라이브러리를 저장하는 과정에서 풋프린트 위치만 처리하고 포함된 금지 영역의 좌표 변환을 잘못 적용하는 문제가 있었다. 이로 인해 L1/U2의 금지 영역이 잘못 저장될 수 있었다. 단순히 검사 경고를 제외하지 않고, 풋프린트를 `fp.SetPosition(0,0)`으로 정규화하는 방식으로 수정했다. 수정 후 프로젝트 내부 라이브러리와 PCB를 다시 검사하여 최종 KiCad 검사 0건을 확인했다. 이 이슈는 원래 회로 설계의 전기적 오류와 구분해서 기록한다.

## 전원 회로 확인과 남은 제약

입력 회로의 USB/AA 전원 선택, PMOS 역극성 보호 방향, TPS63802 핀 연결, USB 데이터 극성, GPIO4 기반 IR 저측 스위칭 연결은 네트리스트 기준으로 일관성을 확인했다.

TPS63802 입력 C10의 명목값 10µF는 제조사 권장값이다. 다만 부품을 고를 때 실제 동작 전압·온도·허용오차에서 실효 용량이 4µF 이상인지 확인해야 한다. 3.3V 출력 C8 22µF는 실효 용량 7µF 이상이 필요하며, 두 콘덴서는 IC 전원·접지 핀 가까이에 배치해야 한다. [TI TPS63802 데이터시트](https://www.ti.com/lit/ds/symlink/tps63802.pdf)

EN을 VSYS에 묶은 기존 시제품 구조는 유지했다. 별도의 AA 저전압 차단이나 배터리 전압 측정 회로는 없으므로 장기 방전 보호 또는 6개월~1년 수명을 보장한다고 기록하지 않는다. SW3는 배터리 경로만 끊으므로 USB가 연결되어 있으면 계속 전원이 들어올 수 있다.

## 최종 소프트웨어 검사와 출력

| 검사 | 결과 |
| --- | --- |
| KiCad 10.0.1 ERC | 오류·경고 0건 |
| KiCad 10.0.1 DRC | 오류·경고 0건 |
| 미연결 | 0건 |
| 회로도/PCB 일치 차이 | 0건 |
| 부품 수·면 | 42개: 앞면 41개, 뒷면 BT1 1개 |
| 잠긴 5개 배치·회전·면 | 입력본과 정확히 일치 |
| 원본 회로도·PCB | 해시 변경 없음 |

검사는 현재 프로젝트의 설정된 error/warning 기준이다. 기존 비활성 검사 목록은 `final-erc.json`과 `final-drc.json`의 `ignored_checks`에 보존되어 있다. 예를 들어 courtyard 미정의나 풋프린트 필터 검사를 비활성화한 설정까지 모두 검사했다고 주장하지 않는다.

`manufacturing/`에 Gerber 9개 레이어, Gerber job 파일, PTH/NPTH 드릴 2개를 생성했다(합계 12개). `manufacturing/assembly/`에는 PCBA 앞면 부품 40개·27개 BOM 묶음의 BOM/CPL과 검토 자료를 저장했다. BT1과 D1은 사용자 수동 납땜 대상으로 제외했고, 혼합형 USB 커넥터 J1은 PCBA에 포함했다.

드릴·실장 원점은 KiCad 절대 좌표 `(64.5,94.0)mm`다. CSV 왕복 읽기, 입력 파일 해시 및 CAM 출력 해시를 검증했다. 자세한 좌표·회전 주의사항은 `manufacturing/assembly/README-assembly.md`에 있다. KiCad의 풋프린트 원점은 실제 흡착 중심과 동일하다고 보장되지 않으며, JLC 부품 방향 보정값을 추측해서 넣지 않았다. 사용자 주문 전에 JLC 미리보기에서 방향·극성·중심을 확인해야 한다.

**Gerber/드릴 출력 자체의 별도 재읽기도 통과했다.** Gerbonara 1.6.3으로 읽은 외곽선 8개, 실제 중심선 기준 85×40mm, PTH 46개(원형 42·슬롯 4), NPTH 6개가 KiCad 좌표·직경·슬롯 끝점과 일치했다. 동박·마스크·페이스트의 예상 패드 중심이 모두 존재하며 원본과 출력 해시도 유지됐다. 비아 38개는 양면 텐팅, 뒷면 페이스트는 비어 있다. KiCad job의 외곽 치수에는 선 두께가 포함되고 별도 파서의 도금 유형 추론에는 한계가 있어 실제 Excellon Plated/NonPlated 헤더를 함께 확인했다. JLC 주문·실물 전원·IR·Zigbee 검증은 이번 완료 범위에 포함되지 않는다.

## 증거 자료와 블로그 반영 원칙

초기 감사 자료는 `tmp/user-pcb-audit-20260920/`의 `netlist.xml`, `erc.json`, `pcb-inspection.json`, `circuit-audit.md`, `passive-land-review.md`에 보관했다. 최종 결과는 작업본 `checks/`의 `final-erc.json`, `final-drc.json`, `release-validation.json`, `cam-export.json` 등을 기준으로 한다. 초기 감사 자료를 수정 후 검증 결과로 오인하지 않는다. 제조사 버튼 도면은 `xkb-ts1187-actual.pdf`와 해당 페이지 렌더에 보존했다. 공개 글에서는 개인 절대 경로 대신 프로젝트 내부 파일명과 상대 경로만 사용한다.
