# 2026-10-02 — 가족 Android 앱

요청: Google 로그인·가족 화면 APK 구현, 독자가 따라할 기록과 캡처, 필요하면 기존 GitHub 연동.
Firebase Android 앱 등록·공개 서명 지문 연결은 사용자가 별도로 승인했다.

## 확인한 사실

- Firebase에 `com.aircon.family`와 전용 SHA-1·SHA-256 등록을 화면에서 확인했다.
- 실제 A50은 Android API 30이고 Google 계정 수는 0개다.
- 기존 A50 관리 앱과 중앙 서버를 사용하는 별도 가족 앱 소스를 작성했다.
- SDK 36·Build Tools 36.0.0·Gradle 8.13 공식 다운로드 체크섬 검증을 통과했다.
- 첫 fixture 빌드는 장시간 의존성 대기를 점검한 뒤 개발자가 프로세스를 중단했다.
  `daemon disappeared`는 그 중단 결과다. 실패 원인을 자동으로 메모리 부족이라고 판단하지 않는다.
- Platform Tools 경고를 확인하고 공식 패키지를 SDK 준비에 추가했다.
- Firebase 다운로드 이벤트 두 차례 시간 초과. 구성 파일 저장은 아직 확인되지 않았다.

## 변경의 범위

로컬 Android 앱과 빌드·시험 도구. 가상 계정·임시 DB의 시험 서버만 별도 실행했다.
운영 API의 공개 노출·공유기 설정·Pi 배포·운영 계정 등록은 수행하지 않았다.
기존 사용자 변경을 유지하고 비공개 구성·개인 키·시험 토큰을 Git에서 제외한다.

실제 Google 로그인은 계정 있는 사용자 휴대폰에서 확인해야 한다.

## 공개 자료와 재현 도구 정리

- 새 가족 빌드·시험 도구 7개는 Ruff 검사·Python 구문 검사 통과.
- 기존 서버 실행 중 재준비 요청은 거부하고 비공개 시험 토큰 원문이 바뀌지 않음을 확인(183~186).
- JDK 17 경로 인자·JAVA_HOME 지원 추가. 임시 관리 빌드 정보 없이도 JDK를 지정할 수 있다.
- 공개 이미지 235개에서 비공개 메타데이터 0개. Git에 올릴 텍스트에서 비공개 설정의
  실제 비밀번호·토큰·장치 식별자와 원문 개인 키·금지 구성 파일을 찾지 못했다.
- 터미널 기록의 줄바꿈·불필요한 끝 공백·탭 표시를 정규화하고 같은 TXT에서 PNG를 다시 생성했다.
  오류 내용·실행 결과·명령은 보존한다. 실제 측정 결과를 새 성공 결과로 바꾸지 않았다.
