# 가족 스마트홈 보안 점검

2026년 10월 3일. 사용자의 보안 질문에 따라 로컬 기준본 `cb11462`의 중앙 서버, 가족 앱, A50 관리 앱을 읽고 A50에 읽기 전용 SSH 점검을 수행했다. 서버 코드 배포, 서비스 재시작, 계정·키·잠금·네트워크 설정 변경은 하지 않았다. 이 기록은 제한된 코드·설정 검토이며 침투 테스트 결과가 아니다.

## 확인된 보호

- 중앙 서버는 Firebase 로그인 토큰의 서명, 프로젝트, 발급자, 만료 시각, Google 로그인 제공자 및 이메일 검증 여부를 확인한다. 사용자 요청마다 활성 계정과 해당 집의 멤버십을 확인하고 소유자 작업은 추가로 제한한다.
- 가족 초대는 지정 이메일에 묶인 일회용 코드이며 24시간 만료된다. 허브 연결 코드는 일회용이고 10분 만료된다. 허브별 비밀 자격 증명으로 서버가 소속 집을 결정하므로 이벤트 요청에서 다른 집을 선택할 수 없다.
- FCM 전송 대상은 집의 활성 멤버십과 휴대폰 설치 연결을 확인해 결정한다. 전송 직전에도 권한을 다시 확인한다. 전송 데이터에는 집 이름이나 센서 측정값을 포함하지 않는다.
- 운영 APK는 HTTPS 연결을 요구하고 시스템 인증서를 신뢰하며 앱 백업을 끈다. FCM 전송용 서비스 계정 개인 키는 서버에서만 사용한다.
- 실제 A50에서 서비스 계정 키, 중앙 서버 설정, 허브 자격 증명, 집 데이터베이스, SSH 공개키 허용 목록의 파일 권한은 모두 `0600`, 서버 설정·데이터 디렉터리는 `0700`이었다. SSH 리스너 실행 옵션에서 비밀번호 및 키보드 대화식 인증 차단을 확인했다. 로컬 중앙 readiness는 HTTP 200, 데이터베이스 상태 `ok`였다.

## 제품 배포 전에 남은 항목

1. **서비스 이용자 제한:** 유효한 Google 로그인을 가진 새로운 사용자는 서버 계정과 빈 집을 만들 수 있다. 다른 집 정보 조회 권한과 서비스 신규 이용 허용은 별개다. 지금은 구매·활성화 코드, 운영자 허용 목록 또는 초대 기반 가입 제한이 없다. 운영 방식에 맞게 신규 이용 정책을 결정해야 한다.
2. **A50 운영 환경:** 실제 Android 버전은 11, 보안 패치 날짜는 `2023-02-01`이었다. 기존 합의로 잠금을 제거하고 자동 관리 연결을 유지한 상태를 고려하면, 제품 운영에서는 업데이트 가능한 중앙 서버와 관리 접근의 분리를 검토해야 한다. 오래된 패치라는 사실만으로 특정 취약점의 악용 가능성이나 침해 발생을 단정하지 않는다.
3. **자원 남용 방지:** 요청 크기·동시 연결·사용자당 설치 수·시험 알림 간격 제한은 있다. 하지만 사용자·요청 종류별 일반 호출 제한, 집 생성 할당량, 이벤트 및 감사 기록 보관 기간 등의 정책은 부족하다. 많은 정상 Google 계정이나 유출된 허브 자격 증명으로 저장 공간과 서버 자원을 소비할 수 있는 경로를 보강해야 한다. Cloudflare 측의 실제 계정별 방어 설정은 이번 점검에서 검증하지 않았다.
4. **인증 철회와 키 운영:** 현재 Firebase 토큰 검증은 Firebase의 계정 비활성화·토큰 철회 상태를 별도로 조회하지 않는다. 서버 자체 계정 비활성화와 집 멤버십 철회는 적용된다. 허브 키 교체 절차, 서버 키 교체 및 백업·복구 운영도 제품 수준으로 정리해야 한다.
5. **외부 연결:** 현재 Quick Tunnel의 HTTPS는 전송을 보호하지만 URL을 아는 사람이 API에 요청하는 것 자체를 막지는 않는다. 집 데이터 권한은 중앙 서버에서 검사한다. Quick Tunnel은 공식 문서상 개발·시험 용도이므로 제품용 고정 운영 경로를 준비해야 한다.

이미 FCM이 받아들인 메시지는 서버에서 회수할 수 없다. 멤버십 철회 이후 API 접근과 아직 전송하지 않은 작업은 차단하지만, 이미 전송된 일반 알림의 도착까지 완전히 취소한다고 설명하면 안 된다. 중앙 서버의 권한 있는 실행 환경이 침해되면 파일 권한만으로 가족 데이터와 서버 키를 보호할 수 없다는 한계도 있다.

## 공식 근거

- [Firebase 사용자 세션과 토큰 철회 확인](https://firebase.google.com/docs/auth/admin/manage-sessions): ID 토큰은 일반적으로 1시간 유효하며 철회 확인은 별도 상태 검사가 필요하다.
- [Firebase App Check](https://firebase.google.com/docs/app-check): 로그인과 별도로 앱·기기 확인을 보완할 수 있으나 모든 남용을 제거하는 보장은 아니다. 현재 프로젝트에는 적용하지 않았다.
- [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/): 임시 URL의 개발·시험 용도와 운영 제한.

권장 우선순위는 신규 이용 제한과 자원 남용 방지, 중앙 서버 운영 환경, 토큰 철회 및 키·백업 운영, 실제 다가족 보안 검증이다. 보완안은 제안이며 아직 적용된 설정으로 기록하지 않는다.
