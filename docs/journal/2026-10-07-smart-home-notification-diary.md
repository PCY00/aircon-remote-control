# 스마트홈 알림 일기 — 2026-10-07

## 블로그 사진을 어디에 넣을지 다시 정리했다

　블로그를 올릴 때 준비한 사진을 본문의 어디에 넣어야 할지 모르겠다는 이야기가 나왔다. 기존 `사진-배치표.txt`에는 파일 이름과 설명만 있었고, 본문 HTML의 사진 위치 메모는 편집 화면에 보이지 않았다.

　원고 9개와 사진 13장을 다시 읽었다. 글마다 부제목과 사진 바로 앞 문단을 가져왔다. 사진 앞에 표나 목록이 있는 곳은 마지막 줄을 적고 표·목록이 끝난 뒤에 넣도록 안내했다. 마지막 글의 홈·기록·설정 사진은 앞 사진 아래에 이어서 넣는 순서를 표시했다.

　`server/scripts/reader/build_tistory_bundle.py`를 바꿔 원고에서 사진 위치를 자동으로 가져오게 했다. 작성자용 `사진-배치안내.html`에는 작은 사진, 파일 이름, 부제목, 바로 앞 문장, 원고에서 해당 위치를 여는 링크를 넣었다. `사진-배치표.txt`와 `읽는법.txt`도 같은 방식으로 바꿨다. 원고 미리보기의 사진 아래에는 올릴 파일 이름이 보이게 했다.

　처음에는 바탕화면에 이전 ZIP이 있을 것으로 보고 읽으려 했지만 파일이 없었다. 실제로는 압축을 푼 원고 폴더가 있었다. 그 폴더의 본문은 바꾸지 않고, 새 게시용 ZIP과 별도의 `A50-사진-배치안내` 폴더를 만들었다.

　사진 13장의 위치가 원고와 모두 같고, 안내의 사진·원고 링크가 실제 파일로 이어지는지 확인했다. 게시용 본문 9개는 이전 내용과 같았다. 공개용 사진에서 개인 메타데이터가 발견되지 않았고, 본문에 로컬 사진 주소도 없었다.

　브라우저 연결이 한 번 끊겨 처음 안내 화면을 캡처하지 못했다. 같은 브라우저의 새 탭에서 다시 열었고, 첫 사진과 넣을 문장이 함께 보이는 화면을 직접 확인하고 캡처했다.

　오늘 날짜의 노션 경로를 실제로 읽었다. 7일의 `일기`에는 이 주제 페이지가 없어 `스마트홈 알림`을 만들고 진행 내용을 적었다. 다른 주제와 일정의 체크 상태는 바꾸지 않았다.

　남은 일은 티스토리 기본 모드에서 안내한 위치에 사진을 올리고 게시 전 미리보기를 확인하는 것이다. 이번에는 티스토리에 사진을 업로드하거나 글을 게시하지 않았다.

　사진 안내 화면의 저장 파일을 처음에는 PNG 확장자로 적었다. 파일 안의 실제 형식은 JPEG였다. 파일을 읽던 작업 때문에 이름 변경이 한 번 실패해 읽기를 닫고 다시 바꿨다. 원본 화면 데이터를 그대로 두고 확장자를 JPG로 맞춘 뒤 개인 메타데이터가 없는지 확인했다.

　노션 최종 저장 상태: 오늘의 `스마트홈 알림` 페이지에 결과를 이어 적은 뒤 다시 읽어 저장된 내용과 7일의 경로를 확인했다.
